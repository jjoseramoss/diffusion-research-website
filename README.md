# Ordering and Timing in Language-Conditioned Diffusion Motion Planning

This UTRGV senior project website presents our experiments with CLoSD's Diffusion Planner. We compare one prompt for a sequence with a new prompt at each action boundary, and test how the time allowed for each action affects the result.

## Tech stack

React, TypeScript, Vite, Tailwind CSS, and Motion.

## Run locally

Install Node.js and npm, then clone the repository:

```bash
git clone https://github.com/jjoseramoss/diffusion-research-website.git
cd diffusion-research-website
npm ci
npm run dev
```

Vite will print the local website address in your terminal.
